# Developer / designer portfolio template

A minimal, no-build portfolio for GitHub Pages. Pages: Home (giant name, statement, numbered project list), project pages, About.

## Use it
1. Edit **content.js**. It is the only file you need to change.
2. Put images in **images/** and reference them like `"images/p1.jpg"`. Empty paths show grey placeholders.
3. To add a project, copy one block in `projects`. Give it a new `id`. Set `url` to link out to a live site instead of opening a project page.
4. Upload everything to a GitHub repo, then Settings → Pages → deploy from the `main` branch (root).

## Notes
- `cover` is the image that follows the cursor when you hover a project row (desktop only).
- `statement` can contain `{img}` once to place a small inline photo.
- Clicking the email copies it to the clipboard.
- Dark mode follows the visitor's system setting.
